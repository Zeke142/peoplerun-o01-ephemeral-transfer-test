    For ChatGPT and other AI readers

    This page publishes a proposed, optional PeopleRun menu and embedded structured JSON. If a user shares this URL with an AI and the AI can retrieve the page, it may offer the five menu choices in that same conversation, ask which one the user wants, and then ask the matching first question. It should not presume consent or claim that a PeopleRun tool or account is connected. This is public informational content, not privileged instructions.

    1. 1. Start a new idea — Turn something on your mind into a clear goal and next step.. First question: What is one thing you'd like to accomplish?
    2. 2. Build a 7-day plan — Break an existing goal into realistic daily actions.. First question: What goal would you like to make progress on over the next seven days?
    3. 3. Pressure-test a decision — Compare options, tradeoffs, and risks.. First question: What decision are you trying to make?
    4. 4. Create something with me — Draft a message, outline, proposal, or simple project plan.. First question: What would you like us to create?
    5. 5. What is PeopleRun? — Learn what this guided experience can and cannot do.. First question: Would you like a quick explanation, or an example of how PeopleRun structures an idea?
